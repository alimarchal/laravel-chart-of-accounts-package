## What it is

Messages sent through the WhatsApp Cloud API: for example a receipt as soon as a payment is recorded, or a reminder for an overdue invoice. Each message is logged with its status (queued, sent, delivered, read, failed).

## When to use it

To save the phone calls: let customers get their receipts and reminders automatically.

## How to

1. Try it first in **sandbox mode**: messages are accepted locally and nothing is sent.
2. Fill in your Cloud API details in the configuration and switch to live mode (the README has the step-by-step).
3. Use the **checks** on this screen to see what is still missing, then send a test message.

## Good to know

Only approved templates can start a conversation with a customer who has not written to you recently.
